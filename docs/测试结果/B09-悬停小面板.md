## 校准轮修正（2026-10-24 对照整体原型第 2 页）

| 项 | 校准前 | 校准后 | 依据 |
| --- | --- | --- | --- |
| 面板圆角 | 14（`radiusPage`） | 10（`radiusControl`） | `.panel{border-radius:var(--r)}`，`--r:10px` |
| 面板阴影 | `0 18 44`、alpha .2 | `0 12 32`、alpha .16 | `--shadow:0 12px 32px rgba(30,50,80,.16)` |
| 标记完成 | 完成后立刻换下一件 | 停在完成态，动作区换成「这件事已标记为完成」 | `renderAction` 里 `if(s.done) → .donenote` |
| 问一问占位 | 固定「有什么我能帮助你的吗？」 | 未接模型时「请前往设置页配置 API key」 | `renderAi` 的 `disabled` 分支 |
| 问一问只读外观 | 无（沿用白底与一档墨） | 底 `#f4f7fb`、字二档墨 | `.ai textarea[readonly]` |
| 多出来的一行说明 | 「接上模型后才能问，先记在随手记里」 | 删掉 | 原型没有这句，占位文字已经说清 |
| 问一问高度 | 只有最小高 36 | 加最大高 104，超出在框里滚 | `.ai textarea{max-height:104px}` |
| 流程轴提示 | 无 | 每段悬停显示步名 | `buildTrack` 给每段挂 `tip` |
| 问答记录 | 状态里有 `answers`，界面没画 | 按 `.answer` 画卡片 | `renderAnswers` |
| 项目名徽标 | 无 | 仍不画（记偏差） | 原型有 `.chip`「已标记」，数据层没有对应字段 |

## 偏差（与 `design.md` 一致）

| 项 | 原型 | 实现 | 为什么 |
| --- | --- | --- | --- |
| 元信息时长 | 「第 N 步 / 共 M 步 · 约 N 分钟」 | 不含时长 | 事项没有预计时长字段，硬造数字比不写更糟；B10 有真实投入时长后补 |
| 开始按钮 | `.go` 可点 | 画出但禁用（`Opacity 0.45`） | 计时服务在 B10，没有它按下去只能假装在计时 |
| 项目名徽标 | `.chip`「已标记」 | 不画 | 数据层没有「手动标记当前事务」的字段，选事务由 B04 规则推出 |
| 玻璃背景 | `.86` + `blur(14px)` | 白 96% | 桌面端实时模糊要另开通道；无模糊时 .86 读不清字，B24 再评估 |

## 排错记录

```text
2026-10-24 面板状态测试编不过：`PanelNotifier get notifier => …` 被解析成 get 局部变量
           报 27 处「The method 'refresh' isn't defined for the type 'Function'」
           改成 `late PanelNotifier notifier;` + setUp 里赋值；随后 `late` 声明落在
           setUp 之后又报 referenced_before_declaration，把声明提到 setUp 之前
2026-10-24 面板界面测试：点标题让随手记失焦不生效
           测试默认平台是 android，TextField 的 onTapOutside 在移动端不 unfocus；
           改成点「问一问」输入框，把焦点挪过去，失焦照常触发
2026-10-24 常驻界面测试：面板渲染后留下一个 300 毫秒的悬停定时器，报
           「A Timer is still pending even after the widget tree was disposed」
           面板档下 MouseRegion 重新命中会再排一次出面板的计时；用例末尾把鼠标挪开
           并多走 600 毫秒，让计时器收掉
2026-10-24 校准轮：`_Track` 里想写「有步名就包 Tooltip、没有就裸段」，先写成
           `element if (cond)` 的元素级 collection-if，Dart 不支持这种位置；
           改成循环里一个三元表达式，段容器抽成 `_segment(i)`，两处复用
```

## 本轮改动

- `data/repository/record_repository.dart` 新增 `daySecondsByProject(yearMonth)`：一次取整月流水，按天再按项目拆秒数，同一事项只查一次。
- 新增 `features/records/records_calendar.dart`：六色表、`soloKey`、格子排布、色带拼接、图例生成、日期文案。
- 新增 `features/records/records_state.dart`：`DayStat` 与 `RecordsState`（含图例高亮与项目色表）。
- 新增 `features/records/records_notifier.dart`：`RecordCalendarNotifier`（注入时钟）+ `recordCalendarProvider`，管切月、回今天、选日、图例高亮。
- 新增 `features/records/month_calendar.dart`：月份条、周标题、42 格、件数、色条、图例；悬停与选中态照原型。
- 新增 `features/records/day_panel.dart`：右栏头部（日期 + `完成 N 件 · 推进 M 个项目`）、空态「这天没有记录」、按投入排序的清单。
- 重写 `features/records/records_page.dart`：左 4 右 6、间距 20，左栏加滚动兜底。
- 新增测试 `test/features/records/` 三份，共 27 条。

## 留的缺口

1. 右栏本轮只到「头部 + 清单骨架」：按项目分组、组头「N 项·M 分钟」、折叠展开归 B18。
2. 日总结、感想、「AI 总结」四态归 B19。
3. 完成件数按事项 `doneAt` 归日，投入按流水开始时间归日；一条事项当天完成、流水记在次日时，件数与色带会分属两天（口径如此，PRD 未要求合并）。
4. 跨零点的会话整段归开始那天，不按分钟切分。
5. 图例高亮只压透明度，不改数据、不筛选右栏。

## 排错记录

写表时有两张表把列名起成了 `text`，撞上 drift 的 `Table.text()` 方法，编译报"递归 getter"；已把 `chat_messages` 与 `progress_entries` 的该列改名为 `content`。

迁移测试第一次失败：`ALTER TABLE settings ADD COL locale TEXT` 被 SQLite 解析成了列名 `COL`、类型 `locale`；SQL 里必须写全 `ADD COLUMN`。改后通过。

数据库文件一度找不到：`path_provider` 在这台机器上把"文档"解析到了 `D:\我的文档`（目录被重定向），不是 `C:\Users\<用户>\Documents`，之前按常规路径搜所以没找到。

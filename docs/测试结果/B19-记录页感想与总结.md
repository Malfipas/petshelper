# B19 我的记录页：感想与 AI 总结四态

范围按 `docs/开发任务拆解.md` B19 与 PRD 第 5 页第 525–526、536–539、546–547 行：每条事项展开后一段 AI 总结按四态显示、旁边一个「编辑」/「写总结」；下面一块「我的感想」；今日小结下面同样一块感想。日总结正文由 B23 生成，这里只负责摆位置与两态提示。

几处口径，代码注释里也写了：

1. **四态顺序照原型**：我改过的 > 没配 key（降级成随手记）> 配了 key 且这条问过 AI（显示整理结果）> 留白。判定是纯函数 `entrySummaryOf`，界面与测试共用，不碰数据库。
2. **感想与总结分开存**，owner 类型不同、键都是 `日期|组键|条目`；今日小结那条的组键与条目都退化成 `summary`。一个 owner 一条，写空即删。
3. **我改过的总结压过生成值**：`userText` 非空就先返回它，之后 AI 再生成也不覆盖。
4. **没配 key 的提醒只有一条，挂在日期行下面**：「请前往设置页配置API key以启用AI总结功能」。原先今日小结与每条总结各挂一句（「先看原始记录」「先按随手记整合」），验收后按用户意见删掉，改由页头统一提醒；条目本身仍降级成随手记原文，只是不再各写一句。
5. **修了一个并发建行的坑**：记录页要读「配没配 key」，一开页 `build` 与 `refresh` 会各读一次设置，两次都发现没这一行就各插一次，后一个撞唯一键把整页打挂。`ensureRow` 改 `insertOrIgnore`。B19 之前没有读设置的路径，所以一直没暴露。
6. **点击区只留标题行**：展开区里是输入框，整卡可点会把「点输入框」也算成收起。原型里 `it` 整块绑 click，这点没照抄。
7. **编辑态失焦或 Ctrl+Enter 保存，Esc 取消**；点「取消」会先触发失焦，等 120ms 看是不是被取消接走了（原型也是这么等的）。
8. 条目没计时也照样能展开：展开区里有总结与感想，只是不画计时的明细行。

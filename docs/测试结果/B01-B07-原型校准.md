## 改动明细

**B01 壳底色与桌面底色此前混成一个值。** `shellBg` 存的是原型 `body` 渐变起点的 `#eef2f7`，而壳要的是 `.main{background:#f2f6fc}`。现在 `shellBg = #f2f6fc` 对上壳，另立 `desktopBg = #eef2f7` 给 `scaffoldBackgroundColor`，原来含糊的 `pageBg` 删除。

**B05 主界面顶部那行产品名是凭空加的。** 原型 `#tabs` 里只有五个按钮，`.tabs` 的起点就是标签排，`:root` 里没有任何产品名字样。删掉标题行，标签排按 `.tabs{padding-left:4px}` 起头。

**B05 壳的内边距与页面纸内边距。**

- `.main{padding:16px 18px 18px}` → `EdgeInsets.fromLTRB(18, 16, 18, 18)`（原本就是这一档，本轮补测试锁住）
- `.sheet{padding:26px 30px}` → `EdgeInsets.symmetric(horizontal: 30, vertical: 26)`（原来是四边 26）

**B05 标签缺 hover 与选中态阴影。** `.tab:hover{color:var(--ink)}` 与 `.tab.on{box-shadow:0 2px 8px rgba(30,50,80,.08)}` 都没落。补上 `MouseRegion` 悬停提字色、选中态 `BoxShadow(0x141E3250, blur 8, offset 0,2)`；标签字号按 `.tab{font-size:14px}` 取 14（令牌五档里没有 14，就地写死并注明）。

**B03 完成是单向的，退回没写。** PRD 483「再点退回未完成」要求三态多选框能退回去。`FinishTask` 加 `done` 参数：退回只翻 `done`/`doneAt`，不删已写下的进度史、不动随手记那条（那条史是「那天确实做完过」的事实）；本来就没完成则回 `FinishTaskAlreadyOpen`。

## 排错记录

**测试里按文案找标签会撞页面标题。** 页面内容区也有「独立事项」这类同名标题，`find.text('独立事项')` 一次命中两个，`tester.widget` 直接 `Too many elements`。改成从标签自己的 key 往下找 `Text`。

**白底落在 `Material` 上，不在 `Container` 装饰里。** `InkWell` 的水波与圆角要一层 `Material` 托着，白底放在它身上；测试原本断言 `BoxDecoration.color == white`，读到的是 null。断言改读 `Material.color`，装饰只验边框与阴影。

**选中态阴影不能画在窗口外。** 原型 `.main` 还有一层 `box-shadow:0 28px 70px`。窗口尺寸正好等于壳，影子画出去会被窗口裁掉，画在窗口内又成了内阴影，所以壳这层不下发阴影，理由写进 `MainShell` 的类注释，留到 B24 与穿透一起处理。

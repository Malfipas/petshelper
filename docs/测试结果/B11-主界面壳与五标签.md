## 改了哪些

- `_TabButton`：白底与边影从「`Material` 白底 + 内层 `Container` 边影」合并到 `AnimatedContainer` 的 `decoration`，`Material` 改成透明只接手势；文字包一层 `AnimatedDefaultTextStyle`。两者都是 150ms / `Curves.ease`。
- `InkWell` 关掉水波与 hover 遮罩（`NoSplash`、透明 `hoverColor`/`highlightColor`）：原型没有这层遮罩，留着会在选中白底上盖一块灰。
- 动画只作用在 `decoration` 与文字样式，`constraints`（minHeight 38）与 `padding`（20）不参与补间，过渡时不重排。
- 测试：4 条标签像素断言原来读 `Container` 与 `Material.color`，改读 `AnimatedContainer` 的 `decoration`，数值一条没改；字色与字重改从 `RichText` 上读（字现在包在 `AnimatedDefaultTextStyle` 里，`Text.style` 是空的）。

## 偏差

| 项 | 原型 / PRD | 实现 | 为什么 |
| --- | --- | --- | --- |
| 打开动效 | `.main` 从右滑入 340ms（PRD 401、426） | 直接出现在正中 | 窗口位置由 `platform/window` 逐帧改，与 B06 档位切换共用链路，塞进来会和贴边吸附打架；留 B24 |
| 页面纸滚动 | `.sheet{overflow:auto}` | 各页自管 | 壳里放滚动容器会给子页无界高度，记录页的左右分栏与固定页脚摆不出来 |
| 外壳阴影 / 遮罩 | `0 28 70px`、背后遮罩 | 不做 | 影子画到窗口外会被裁；遮罩要全屏窗口，会挡桌面操作，与 PRD 316 冲突；B24 |

## 顺延

- 实机手动项：标签换态的手感、点桌宠收起、Esc 收起、切页时壳不闪，与 B06–B10 的窗口项合并到 Windows 上点。
- B12 起各页自己在页面纸里滚动。

## 排错记录

**`TaskSource` 缺 `dbValue`。** 写库时 `TaskSource.created.dbValue` 报 undefined，因为 `row_mappers.dart` 里的枚举转换只写了 `TaskScope`、`NoteOwner`、`ChatOwner`、`RevisionTarget`、`ChatRole`、`PetSide`，漏了 `TaskSource`。补上 `TaskSourceX` 后消除。

**假端口自增 id 与旧 id 撞车。** `MoveTask` 测试首跑在 `move_task.dart:41` 抛空值：假 `createForProject` 用 `'t${++_seq}'` 生成新 id，第一条正好是 `t1`，与旧事项同 id，随后 `delete('t1')` 把刚建的那条删掉，`byId(newTaskId)` 拿到 null。真实实现用 `newId('t')` 带随机尾数，不会撞。把假实现改成 `'tp${++_seq}'` 后通过——顺带说明这条测试确实在验「换新 id」这件事，而不是在验假实现的编号规则。

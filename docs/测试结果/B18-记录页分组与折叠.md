几处口径，代码注释里也写了：

1. **组头 `3/7` 是当前步/总步**（PRD 原话），0 基换 1 基，没开始写 `0/7`；项目没有步骤就不画徽标。
2. **距截止按选中那天算**，不按今天。回看旧日子看到的是那天的处境。
3. **推进说明先说当天收尾的那一步**（当天完成、且这步没有剩活），编号最大的那个；没有收尾的步才说「最后动过的那一步 推进中」。收尾是这一天最该记下来的事，压在「推进中」前面。
4. **组内按当天时刻升序**，同一刻按事名，没时刻的垫底。回看一天怎么过的，先后比时长有意义；B17 原先按秒数降序，这轮改掉。
5. **只标记完成、没跑秒的事项现在也进右栏**（B17 修正时已让推进数算上它们，这里补上条目本身）。这类条目不提计时：元信息只写时刻（`15:00`），没有时长就不写时长；展开区没有事实可讲，返回空串，界面据此不画箭头、点击也不响应，免得点了像坏了。
6. 组内合计 0 秒写「0 分钟」，不用「不到 1 分钟」。

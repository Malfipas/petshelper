## 改了哪些

- 页面整页新建：B05/B06 时这里是 `ComingSoon` 占位，`page-solo` 键留在最外层 `KeyedSubtree` 上，壳认页的逻辑没动。
- 计时数字不从页面自管：`running`/`paused`/`clockLabel`/`taskId` 全从 `panelNotifierProvider` 取。页面只决定按钮画哪一种，「开始」之后由面板接着跑。
- 暂停态判定改了两次才对：面板的 `running` 在暂停时仍是 `true`（它表示「这一轮还没停」），所以本页要用 `running && !paused` 与 `running && paused` 分开画，否则暂停后按钮一直是蓝色走秒。
- 当前行左边那条 3 像素竖条：原来用 `Row(crossAxisAlignment: stretch)` 拉满，列表里高度无界会直接抛 `BoxConstraints forces an infinite height`，改成 `Stack` + `Positioned`。
- `PanelNotifier` 的两处异步回填（`refresh`、`_apply`）补 `ref.mounted`：页面退出后读库才回来，原写法会往已销毁的容器里写状态。
- `SoloListNotifier.build` 里补一次 `reload()`：列表没有别处预热，不主动拉就一直空白。
- 相对日期 ≥30 天时按中文说「一个月前」，不写「1 个月前」，与「一周前」同一口径。

## 偏差

| 项 | 原型 / PRD | 实现 | 为什么 |
| --- | --- | --- | --- |
| 「当前」标记 | 原型另存 `marked` 字段 | 取面板当前事务（`taskId` 一致且未完成） | 当前事务只有一个来源；另存一份会立刻分叉 |
| 保存提示 | 原型左下事件台打一行 | 标题排右侧一行灰字，1.8 秒自清 | 事件台是演示控制台，不是产品部件 |
| 移到项目的 id | `mv-项目-时间戳` | `MoveTask` 换 `newId('t')`，流水改挂、秒数带走、随手记 `moveOwner` | B04 已定并测过；两边账仍然对得上 |
| 点开始 | 面板叠在主界面右侧，主界面不关 | 主界面收起、窗口落面板档 | 只有一档窗口尺寸，同屏会挤；PRD 469 也写收起 |
| 页面滚动 | 整页 `overflow:auto` | 标题排固定，只滚列表 | B11 已定：壳不提供整页滚动 |
| 计时行没跑时 | 单页原型写「没在计时」 | 只写累计 | 整体原型是后出的 |
| 已完成次日移出 | 原型只承诺不过滤 | 按 `doneAt` 本地日期过滤 | 不过滤就一直挂着 |
| 在跑时删除 / 移动 / 勾完成 | 直接清掉计时 | 先 `panel.stop()` 结算 | 不丢已投入的时间 |
| 相对时间 | 原型写死四种 | 六档（今天 / 昨天 / N 天前 / 一周前 / N 周前 / N 个月前） | 真实时间戳必须有全跨度规则 |

## 顺延

- 实机手动项：多选框三种颜色的实际观感、卡片 140ms 换底、虚线在 1 倍屏与 2 倍屏下的清晰度、点「开始」后主界面收起与面板落位是否连贯，与 B06–B11 的窗口项合并到 Windows 上点一轮。
- 「已完成次日移出」只在数据层验过（昨天完成的不进列表），跨零点那一刻的实际观感（页面正开着过夜）等实机确认。

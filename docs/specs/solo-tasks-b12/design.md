# B12 独立事项页 · 设计

## 概述

页面本身是「一列卡片 + 行头 + 行内详情」，没有新表：读写都走 `TaskRepository`（`solo/createSolo/rename/setDescription/delete`）、`NoteRepository`、`MoveTask`、`FinishTask`。所有「跑着的秒数」都来自 `panelNotifierProvider`，页面不另起一套计时，也不自己算当前事务。

对应需求：FR-01/02/03/06/08 是布局与控件；FR-04/05/10 是排序、三态与元信息；FR-07/09 是计时接入与保存。

## 技术方案

### 状态

`SoloListNotifier`（`Notifier<SoloListState>`，非 autoDispose）：

- `items`：`TaskRepository.solo()` 取回后排序；已完成只留 `doneAt` 落在今天的。
- `openId`：展开的那条，`null` 表示都收起。放 Notifier 而不是页面本地，是因为壳的 Esc 要先问它。
- `projects`：展开详情时拉一次 `ProjectRepository.digests()`，给「移到项目」用。
- `flash`：`已保存 · 名字` 这类一行提示，1.8 秒后自己清掉。
- `now`：构造参数注入，测试里给固定时钟。

刷新时机：`build()` 里先拉一次；`ref.listen(panelNotifierProvider)` 看到「由跑着变停」或「当前事务换人」就重新拉——面板里按停止、按完成、切事务，本页都跟着动。

走秒不另起定时器：页面 `watch` `panelNotifierProvider`，`running && taskId == item.id` 时把 `clockLabel` 摆进按钮，计时行也因此每秒刷新。

### 组件

```text
SoloPage (ConsumerStatefulWidget)
├─ 标题排：Text('独立事项') + 提示（flash）+ 新建键
├─ 新建表单（本地 state：展开、名称、说明；名称空则确定禁用）
└─ Expanded > ListView
   └─ _SoloRow（每行）
      ├─ 行头：_CheckBox + 名称/元信息（42%）+ 说明（flex）+ 当前角标 + 开始/走秒/已完成
      └─ 展开时：_SoloDetail（StatefulWidget，key=item.id）
         ├─ 计时行
         ├─ 名称 / 说明 / 随手记
         └─ 保存 / 删除 / 移到项目（＋已完成提示）
```

详情里的三个输入是 `TextEditingController`，`initState` 时从 item 与 `noteRepository.textOf` 灌值；`onChanged` 起 600ms 防抖，调 `notifier.autoSave`。整行点击展开，输入框与按钮都 `stopPropagation`（`GestureDetector(onTap: () {})` 包一层或直接不给外层吸收）。

### 命令

| 动作 | 落到哪 |
| --- | --- |
| 新建 | `TaskRepository.createSolo(name, description, nowMs)` |
| 开始 | `panel.setCurrentTask(id)` → `panel.start()` → `pet.openPanel()` → `context.go('/pet')` |
| 点走秒块 | `pet.openPanel()` → `context.go('/pet')` |
| 勾完成 | 正在跑先 `panel.stop()`；`FinishTask(done: true/false)` |
| 删除 | 正在跑先 `panel.stop()`；`tasks.delete` + `notes.deleteFor` |
| 移到项目 | 正在跑先 `panel.stop()`；`MoveTask(taskId, projectId, nowMs)` |
| 自动保存 / 保存 | `rename` + `setDescription` + `notes.save`；保存另收起详情并置 flash |
| Esc | `notifier.collapseDetail()` 返回 true 就在壳里吃掉，否则走原有的收壳 |

`PetNotifier` 补一个 `openPanel()`：跳过 300ms 悬停延迟，直接把常驻档切到面板档。点「开始」后主界面要收，档位得落在面板，不能停在主界面档等悬停。

### 规则

- 相对创建日：0 天「今天建的」、1 天「昨天」、2–6 天「N 天前」、7–13 天「一周前」、14–29 天「N 周前」、≥30 天「N 个月前」（按本地日历日差算，不按 24 小时）。
- 分钟：`max(1, (秒 / 60).round())`；行内只在 `spentSec > 0` 时追加。
- 已完成当日可见：`doneAt` 的本地日期等于今天的才进列表，跨天自动消失，不需要定时器——每次刷新重算。

## 偏差表

| # | 项 | 原型 / PRD | 实现 | 为什么 |
| --- | --- | --- | --- | --- |
| 1 | 「当前」标记 | 原型另存 `marked` 字段，`开始` 时改写它；种子数据里也有一条天生 marked | 不存字段，`当前 = 面板当前事务`（`panel.state.taskId` 且未完成） | 真实产品里「当前事务」只有一个来源，就是面板摆的那件。再存一个标记会立刻分叉：面板换事务、本页角标不动。角标外观与「开始后立刻出现」都对得上 |
| 2 | 保存提示 | 事件台（原型左下 `console`）打一行「已保存」 | 标题排右侧一行 12 号灰字，1.8 秒后淡出 | `console` 是原型的演示控制台，不是产品部件，产品里没有事件台；提示又不能没有，就地做最轻的一行 |
| 3 | 移到项目的 id | `mv-项目-时间戳`，项目页从 localStorage 里读 | `MoveTask` 换 `newId('t')`，流水改挂、秒数带过去、随手记 `moveOwner` | B04 已按产品需要定下这条规则并测过：新 id 比拼字符串更稳（同毫秒重复、项目改名都不怕），而「两边账要对得上」正是原型拼 id 想干的事 |
| 4 | 点开始 | 面板叠在主界面右侧，主界面不关 | 主界面收起、窗口落面板档 | 窗口只有一档尺寸：面板与主界面同屏会挤在一起。PRD 469 也写「主界面收起」 |
| 5 | 页面滚动 | `.sheet{overflow:auto}` 整页滚 | 标题排固定，只滚列表 | B11 已定：壳不提供整页滚动，各页自管 |
| 6 | 计时行没跑时 | 单页原型写「· 没在计时」，整体原型只写累计 | 按整体原型 | 整体原型是后出的 |
| 7 | 已完成次日移出 | 原型只在文案与 `log` 里承诺，`render()` 并不过滤 | 按 `doneAt` 本地日期过滤 | 不过滤就一直挂着，承诺变空话 |
| 8 | 在跑时删除 / 移动 / 勾完成 | 直接清掉计时，秒数丢弃 | 先 `panel.stop()` 结算再操作 | 结算才不丢用户已经投入的时间 |
| 9 | 相对时间 | 原型只写死四种（今天建的/昨天/3 天前/一周前） | 六档：今天 / 昨天 / N 天前 / 一周前 / N 周前 / N 个月前 | 数据是真实时间戳，必须有覆盖全部跨度的规则 |

## 测试

Notifier（注入固定时钟与内存库）：

1. 新建后排在最前、元信息是「今天建的」。
2. 勾完成沉到最底、带 `doneAt`；再点退回原位。
3. 昨天完成的种子不进列表，今天完成的进。
4. 自动保存写回名称、说明、随手记；名称留空回退。
5. 保存后详情收起、flash 是「已保存 · 名字」，1.8 秒后消失。
6. 删除连带随手记；移到项目后本页无残留、项目里多一条、随手记跟过去。
7. 同时只展开一条；`collapseDetail()` 收掉后返回 true。

页面（`SoloPage` 注入内存库，壳外用 `MaterialApp` 包一层）：

8. 标题 16/600、新建键 34 高、下留 20；空态文案与入口。
9. 新建：名称空时确定禁用；填名建成后列表出现、表单收起。
10. 行高 72、名称列占 42%、开始键最小宽 88；已完成行按钮写「已完成」且禁用。
11. 详情展开：计时行写「累计 N 分钟」，输入框初值与随手记灌好；点保存后收起。
12. 点开始：计时服务在跑、面板当前事务是这一件、`openPanel` 后档位是面板。

13. Esc 先收详情，再按一次才收壳。

# 03 · 市场分析

## 结论

**值不值得占**：值得。理由是位置空。

**谁在占**：四类各占一角。通用待办解决"别忘了"，番茄钟解决"开始之后怎么撑住"，ADHD 辅助应用解决"拆得动"，通用 AI 助手解决"问得到"。没有一类把四件事连成一条。

**空隙在哪**：常驻桌面、自己出现、替你搭结构，这三件同时做到的一家都没有。

## 完整分析

### 谁在占

| 类 | 代表 | 解决什么 | 不解决什么 |
| --- | --- | --- | --- |
| 通用待办 | 滴答清单、Things | 别忘了 | 不会做 |
| 番茄钟 | 番茄 ToDo、Forest | 开始之后的专注 | 开始之前的那一步 |
| ADHD 辅助应用 | Tiimo、Goblin Tools、Inflow | 把大任务拆小、减少决策点 | 多数还要你自己打开它 |
| 通用 AI 助手 | ChatGPT、豆包 | 问什么答什么 | 不问就不说 |


### 这类产品在国内的情况

国外有一批专做 ADHD 辅助的产品，国内几乎空白。

**但空白不等于机会。**没人做，可能是因为做不起来。

### 其余维度

| 维度 | 结论 |
| --- | --- |
| 细分 | 两条线：ADHD 专用与通用效率。本产品在两者之间 |
| 趋势 | ADHD 在中文互联网上正从医学议题变成自我认同标签 |
| 人口 | 儿童患病率 6.4%，约 65% 症状延续到成年；女性漏诊率高达 80% |

| 经济 | 目标人群是学生与年轻白领，付费能力弱，也没有机构替你付费的通道 |
| 技术 | 大模型把"拆解任务"从难事变便宜事，这是过去做不成现在能做的关键 |
| 消费者反馈 | 抱怨集中在两点：功能太多用不起来、提醒太多变成噪音 |

## 商业模式画布

填的顺序是定对谁做，再定给什么，然后倒推自己要有什么，最后算账。

| 格 | 结论 |
| --- | --- |
| ① 客户细分 | 坐在电脑前、知道手头的事重要也愿意做，却看不见全貌所以迈不出第一步的成年人，自述注意力缺陷的占多数 |
| ② 价值主张 | 在那一刻自己出现，把一件模糊的大事变成看得见的路径，每次只给一个能做的动作 |
| ③ 渠道通路 | 开源仓库与 ADHD 社群，再靠用起来之后的口碑；零推广时口碑等于零，实际只够得着一小部分人 |
| ④ 客户关系 | 工具型，一次性交付；没有续费与客服，陪伴那一层不收钱 |
| ⑤ 收入来源 | 没有。目标是学生与年轻白领，付费能力弱，也没有机构替他们付钱 |
| ⑥ 核心资源 | 只有一条不可替代：自己对这件事的第一手经验。模型能力与界面谁都能拿到，不算资源 |
| ⑦ 关键业务 | 开发，自己每天用，再把用出来的判断写进文档 |
| ⑧ 重要合作 | 只有模型供应商一家，且可替换。说不出"没有它干不成什么"的，都不算合作 |
| ⑨ 成本结构 | 几乎全是时间，不折成钱；现金只有模型按量调用，一个人用的量级可以忽略 |

**核心结论**：收入为零，成本也近乎为零，它成立正因为两头都接近零。所以它谈不上生意，只是一个能自持的项目。这和上文「空白不等于机会」是同一条判断的两面：国内没人做，可能因为这块收不回成本；它不靠收回成本活着，那条理由管不到它。

**四项检查**：没人付钱，模式里也就没藏着第三方；愿意付的理由不存在，成立理由是作者自己愿意做；收入与成本同为接近零，量级对得上；渠道只够得着一小部分同类人。

## 判断

1. **空白不等于机会。**国内没人做 ADHD 辅助，可能因为诊断率低、认知晚，也可能因为这块根本收不回成本
2. **付费能力弱。**学生与年轻白领，且没有保险或雇主替你付钱这条路

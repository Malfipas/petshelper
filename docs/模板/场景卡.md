# 场景卡

**用在**：阶段 1（发现）。
**怎么用**：一张卡 = 一次**真实发生过**的事，不是"以后可能会发生"的事。复制下面那段，每张卡一份。

为什么要求"真实发生过"：想象出来的场景会把后面的所有阶段带偏。你会照着想象中的问题做功能，然后发现自己根本不用它。

**判定标准**：翻回去看这张卡时，你能回忆起当时的画面。回忆不起来，就说明这是编的。

---

## 场景卡：<给这件事起个短名>

**什么时候、在哪**：<大致时间 + 情境，例如"上周三晚上，宿舍桌前">
**当时在做的事**：<具体到在做什么。不写"工作""学习"这类笼统词>
**卡在哪一步**：<从"打算做这件事"到"停下来"之间，具体是哪一下卡住了>
**当时的应对**：<你实际做了什么。包括刷手机、换一件事做、硬着头皮做完>
**为什么失效**：<那个应对解决了什么、没解决什么>
**若有助手，本可以怎样**：<一句话。这里不写功能需求，写"当时希望有人替我做/提醒我做什么">

**归属痛点**（选一个）：启动不了（起不来 / 不想动 / 动了会愧疚）/ 决策内耗 / 留不住东西

## 可分发构建

| 项 | 内容 |
| --- | --- |
| 构建产物 | `dist/桌宠日常助手-1.0.0-win64.zip`（13.8 MB）→ 解开是 `dist/桌宠日常助手-1.0.0/`，23 个文件 / 32.8 MB，其中 `flutter_windows.dll` 20.3 MB、`data/` 里是 `app.so` 与资源 |
| 怎么生成的 | `cd app; powershell -ExecutionPolicy Bypass -File tool\package_windows.ps1`。脚本先 `flutter build windows --release`，再把 `build\windows\x64\runner\Release` 拷进 `dist\`、附一张 `运行说明.txt`、压成 zip。带 `-Inno` 且本机装了 Inno Setup 6 时，再出 `setup.exe`（脚本在 `app/installer/ai_pet_assistant.iss`） |
| 放在哪 | 仓库里的 `dist/`。**它不入库**（`.gitignore` 里 `/dist/` 与 `*.zip`），所以交付靠拷给别人或挂到远程仓库的 Release 附件上 |
| 怎么启动 | 解压后双击 `ai_pet_assistant.exe`。第一次不会铺满屏幕，桌宠在屏幕右缘，鼠标移上去出小面板 |
| 依赖什么 | Windows 10/11 x64。不依赖 Flutter、不依赖 Dart。理论上依赖系统的 VC++ 2015–2022 运行库（Win10 起一般自带，缺了会报 `msvcp140.dll` 找不到）——这一条没在裸机上验过，见下面的安装记录 |

**判定基准**：如果需要"先手动改个配置""先自己装个环境再说"，那就**不算装得上**。上面这一版不需要改任何配置，key 在界面里填。

## 干净环境安装记录

**做法**：换一台机器，或者在本机新建一个用户账户，从零装一遍。

**为什么不能在自己开发机上试**：开发机上什么都有了，所以永远装得成功。这条路骗过无数人。

| 步骤 | 我做了什么 | 顺利吗 | 踩了什么坑 |
| --- | --- | --- | --- |
| 1 | 把 `dist/桌宠日常助手-1.0.0-win64.zip` 解压到 `%TEMP%` 下一个空目录（不在仓库内、不在 build 目录） | 顺利 | 解压后目录名带中文，路径长度正常，没有出现乱码 |
| 2 | 双击那个目录里的 `ai_pet_assistant.exe` | 顺利 | 没有出现缺 DLL 的报错；进程起来后内存约 129 MB，界面正常 |
| 3 | 让它跑 6 秒后确认进程还在（不是闪退） | 顺利 | — |
| 4 | 在**另一台机器**或**本机新建标准用户**下从零装一遍 | **没做** | 这是本阶段唯一没过的一格。dev 机上装了 Flutter SDK、VC++ 运行库、WebView 等一大堆东西，同机换目录启动只能证明"不依赖 build 目录与仓库结构"，不能证明"干净机器能跑" |

**如实说明**：第 1–3 步已做，证据是本文档的这张表与 `docs/测试结果/B24-打磨与发布.md`。第 4 步没做，所以下面 B 段不勾。

## 使用说明

给拿到包的人看的那一份在包里：`运行说明.txt`（`tool/package_windows.ps1` 每次打包时生成，UTF-8 BOM，记事本打开不乱码）。内容四段：

- **怎么开**：双击 exe；第一次不铺满屏幕是正常的，桌宠在右缘；鼠标移上去出面板，面板里点「展开」进主界面。
- **用 AI 之前**：主界面 → 设置 → 填 OpenAI 兼容服务的 key（默认 DeepSeek）→ 保存。不填也能用，只是四处 AI 入口不出结果。
- **怎么退出**：右键托盘 → 退出。直接关主界面只是收起，进程还在，这是故意的。
- **怎么清干净**：退出程序，删 `文档目录/app.db`，再删 `%APPDATA%\com.aipet\ai_pet_assistant\api_key.bin`。

**判据**：一个没用过的人（或者几个月后的你）不问就能跑起来。上面四段是照着这个判据写的：只说"怎么开、填什么、怎么退、怎么清"，没写一句架构。

## 隐私说明

这个产品会把你写的东西发出去（发给模型）。这一节必须写。

| 问题 | 答案 |
| --- | --- |
| 数据存在哪 | 数据库：`文档目录/app.db`（本机 `D:\我的文档\app.db`），SQLite 单文件。API key：`%APPDATA%\com.aipet\ai_pet_assistant\api_key.bin`，DPAPI 加密，只有当前 Windows 用户在本机能解开 |
| 哪些数据会离开本机 | 只有四次 AI 请求的正文，且每次都只发这一次要用的那点东西：①任务拆解＝项目名＋你写的目标＋（可选）附件内容；②问一问＝你这一句＋（可选）附件内容；③想法归类＝这条想法的标题与正文；④日总结＝当天的日期、完成件数、总分钟数、事项名与各自时长、随手记原文 |
| 哪些数据永远不出本机 | 数据库文件本身、API key、其他项目与其他日期的内容、进度史与修订记录、设置项、窗口位置。请求里不带历史对话，不带你没打开过的页面的数据 |
| 用到了哪些第三方服务 | 默认 `https://api.deepseek.com`，模型 `deepseek-chat`；换成任何 OpenAI 兼容的 `baseUrl` 与模型名都行，换哪家就发到哪家。没有埋点、没有崩溃上报、没有更新检查 |
| 怎么把自己的数据删干净 | 退出程序 → 删 `app.db` → 删 `api_key.bin`。两处都在本机，删完即无残留。程序不写注册表（除了自启那一项 `HKCU\...\Run\AIPetAssistant`，设置页关掉自启即删） |
| 图片附件怎么算 | 选了图片附件时，图片按 base64 放进请求的 `image_url` 段一起发出去。单张 ≤ 4 MB、一次 ≤ 5 个，超了在界面里拒掉，不会偷偷压缩后上传 |

**这一节和[阶段 4](07-开发.md)的模型选型表是同一件事的两面**：那边记"为什么这么选"，这边写"所以什么会发出去"。

| 版本 | 日期 | 变更 | 对应解决的是哪个问题 |
| --- | --- | --- | --- |
| v1.0.0 | 2026-10-27 | 首个可用版本：桌面常驻桌宠（三档尺寸、贴右缘、拖得动）、悬停小面板、两档气泡（截止强提醒＋开机播报）、独立事项与计时、我的记录（日历着色、进度史、随手记、AI 日总结）、我的项目（项目→步骤→事项三层、进度史与时间轴）、想法盒（AI 归类）、设置页（key 存系统安全存储、开机自启、托盘）；AI 四处接入（拆解、问一问、归类、日总结），全部带降级 | **启动不了**：桌宠常驻在屏幕边，面板里只有"今天这一件事、第几步"，把"要做什么"从回忆变成看见。<br>**决策内耗**：拆解把一个大目标变成能动手的几步，不用自己先想清全场。<br>**留不住东西**：计时自动记流水、想法一粘就进盒、日总结把一天收成一段，都留得下 |

**"对应解决的是哪个问题"这一列必须填**：填不出来的变更，说明它是顺手加的，通常也是可以不加的。

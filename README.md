# AI桌宠日常助手

一个以桌面陪伴形象存在的日常助手。它不催你、不弹窗，坐在屏幕边上一个不碍事的位置；鼠标移上去才露出小面板，面板里就是「今天这一件事，第几步」。

要解决的问题是三个：

- **启动不了**：含三个子状态，起不来、不想动、动了会愧疚，对策各不相同
- **决策内耗**：算不清每个选择的后果，最后被决策本身压垮
- **留不住东西**：想法和做过的事都没留下可找回的痕迹

桌宠形态的两个理由：**在不影响办公视觉的前提下便捷唤出助手**，以及**增加些许陪伴感**。产品是**通用日常助手 + 项目制**，求职、配音、毕业论文平级共存，不是求职专用工具，原因见 [ADR-0001](docs/adr/0001-定位为通用日常助手而非求职助手.md)。

## 快速开始

**装**（拿到 `桌宠日常助手-1.0.0-win64.zip` 的人）：

1. 整个目录解压到任意位置，双击 `ai_pet_assistant.exe`。第一次打开不会铺满屏幕，桌宠出现在屏幕右缘。
2. 鼠标移到桌宠上出现小面板，点「展开」进主界面。
3. 主界面 → 设置 → 填一个 OpenAI 兼容服务的 API key（默认 DeepSeek）→ 保存。不填也能用，只是拆解、问一问、想法归类、日总结这四处不出结果。
4. 退出走托盘右键；想让下次开机自己出现，设置页把「开机自启」打开。

Windows 10/11 x64，不需要装 Flutter，包里也没有任何联网安装步骤。

**自己构建**（要改代码的人）：

```powershell
cd app
flutter pub get
flutter run -d windows          # 开发时跑
flutter test                    # 643 条
dart analyze lib test           # 必须 No issues found!
powershell -ExecutionPolicy Bypass -File tool\package_windows.ps1   # 出 dist 里的 zip
```

环境：Flutter 3.47.7 stable、Dart 3.11、Windows 10/11 x64。数据库表改了之后跑一次 `dart run build_runner build --delete-conflicting-outputs` 重新生成 `app_db.g.dart`（这个文件已入库，一般不用管）。

## 目录结构

```
AI桌宠日常助手/
├── app/                         # Flutter 工程，能跑的那部分全在这里
│   ├── lib/
│   │   ├── app/                 # 壳、路由、主题、providers 一处装配
│   │   ├── features/            # 按八页切：pet panel tasks records projects ideas settings
│   │   ├── domain/              # 实体、用例、端口（纯 Dart，不 import Flutter）
│   │   ├── data/                # drift 数据库、DAO、Repository、迁移、行映射
│   │   ├── platform/            # 窗口、托盘、自启、安全存储、计时
│   │   └── ai/                  # 客户端、提示词、结构化解析、降级
│   ├── test/                    # 643 条，目录结构与 lib 对齐
│   ├── tool/                    # package_windows.ps1：构建 + 打包
│   └── installer/               # Inno Setup 脚本（有 iscc 才用得上）
├── docs/                        # 十段文档、ADR、模板、测试结果、验收表
├── prototype/                   # 用完即弃的 HTML 原型，不并入正式工程
├── state/                       # 恢复入口与状态记录
├── assets/                      # 桌宠素材原图（设计过程产物，运行时不用这份）
└── dist/                        # 打包产出，不入库
```

运行时真正加载的图只有三张，在 `app/assets/桌宠/`：常驻左 `常驻-240.png`、常驻右 `常驻右-240.png`、展开 `展开-360.png`。根目录 `assets/` 是尺寸对比与备选稿，评审时可看，程序不读。

## 功能一览

| 功能 | 落在哪 | 一句话 |
| --- | --- | --- |
| F1 开机自己出现 | 托盘 + 自启 | 常驻不占任务栏，右键托盘退出 |
| F2 显示今天那一件事 | 悬停面板 | 面板里只有「项目 · 第几步 · 这一件事」 |
| F3 两档气泡 | 桌宠头顶 | 截止强提醒，与开机时的项目现状播报 |
| F4 执行与计时 | 小任务窗口 | 开始 / 暂停 / 完成，时间自己走 |
| F5 拆到不用下决心 | AI 帮助 | 说一句目标，拆成能动手的几步，预览后再落库 |
| F6 停手自动记流水 | 计时服务 | 中断即记，不用手动填 |
| F7 记录可改留痕 | 记录页 | 每次改都留一条修订 |
| F8 想法盒与归类 | 想法盒 | 粘一句进来，AI 给个分类 |
| F9 项目容器 | 项目页 | 项目 → 步骤 → 事项三层 |
| F10 进度史与日总结 | 记录页 | 时间轴 + 当日一段小结 |
| F11 日历着色 | 记录页 | 有记录的日子才亮，标完成件数 |
| F12 设置与 key | 设置页 | key 存系统安全存储，不进数据库、不进日志 |

## 数据放在哪

- 数据库：`文档目录/app.db`（本机是 `D:\我的文档\app.db`），drift + SQLite。
- API key：`%APPDATA%\com.aipet\ai_pet_assistant\api_key.bin`，DPAPI 加密，只有当前用户当前机器能解开；文件被拷走也读不出明文。
- 想清干净：退出程序 → 删 `app.db` → 删上面那个 `api_key.bin`。

## 已知边界

- 只有 Windows x64。macOS 与 Linux 的 key 安全存储没有实现，写 key 会明确失败，不做「悄悄存明文」这种降级。
- 单机。没有账号、没有云同步，换机器要重新填 key、数据库要自己拷。
- AI 依赖外部服务，断网或额度用尽时四处入口都退回本地行为（想法留未分类、日总结退回随手记整合），不假装成功。
- `.agents/`、`.codebuddy/`、`.mcp-probe-kit/` 这些是开发时用的 AI 辅助工具链，不入库；克隆后要用就按 AGENTS.md 重跑一次 `init_project_context`。

# 桌宠日常助手

<p align="center">
  <img src="app/assets/桌宠/展开-360.png" width="200" alt="桌宠">
</p>

一个坐在 Windows 屏幕右缘的桌宠。它不催你、不弹通知、不占任务栏；鼠标移上去才露出一个小面板，面板里只有一句话：**现在这件事，第几步**。

它解决的不是"该做什么"——待办清单已经够用了。它解决的是卡住那一刻：明知道该干活，但身体不动。它自己出现，把"该做什么"缩成"现在做这一步"。

- **不用你想起它**：开机就在右缘，点一下是主界面，不点它就一直安静待着
- **不用你做计划**：说一句"我想把配音练完"，AI 拆成能动手的几步，看过再落库
- **不用你记着写**：开始、暂停、停止都在面板里点，时间自己记，中断也留痕

适合手上同时压着几件长期的事、总是迈不出第一步、而工作就在这台 Windows 电脑上的人；不适合要多人协作与甘特图的项目管理，也不是一个会说话的挂件。

## 它长什么样

主界面是五个标签：

| 标签 | 里面是什么 |
| --- | --- |
| **独立事项** | 没有归到项目里的杂事。点「开始」收起主界面，在桌宠旁边计时 |
| **我的项目** | 求职、配音、毕业论文这样的事各自一个项目。项目 → 步骤 → 事项三层，点开看进度史与时间轴 |
| **我的记录** | 左边日历（有记录的日子才亮，标完成件数），右边某一天的明细与「今日小结」 |
| **想法盒** | 路上冒出来的一句话先扔进来，AI 给它归个类，回头再处理 |
| **设置** | 模型 API key、项目地址、开机自启 |

桌宠头顶还会飘两种气泡：截止日期临近时的强提醒，和每次启动时的一遍项目现状播报（"配音练习 18%，1/7，前天"）。点「查看」直接落到那一条。

## 装上

**方式一：下载打包好的版本**

到 [Releases](https://github.com/Malfipas/petshelper/releases) 页下 `桌宠日常助手-x.y.z-win64.zip`，整个目录解压到任意位置，双击 `ai_pet_assistant.exe`。不需要装 Flutter，包里也没有任何联网安装步骤。

**方式二：自己构建**（见文末「开发」）

系统要求：Windows 10 / 11 x64。理论上需要 VC++ 2015–2022 运行库，Win10 起一般自带；缺了会报找不到 `msvcp140.dll`，装一次微软的运行时即可。

## 第一次用

1. **看它出现**。第一次打开不会铺满屏幕，桌宠在屏幕右缘，这就是正常状态。
2. **点它**。宠物切到展开形态并出现在屏幕中央，就是主界面。
3. **填一个 key**（可选）。设置 → 「API key」→ 粘贴一个 OpenAI 兼容服务的 key（默认 DeepSeek）→ 保存。
4. **建第一条**。独立事项页「新建事项」，写个名字就行；或者在我的项目页新建一个项目，用 AI 帮助把步骤拆出来。

**不填 key 也能用**：新建、计时、记录、日历、项目与进度史全部照常，只有四处 AI 入口不出结果——项目拆解、面板里的问一问、想法归类、今日小结。这几处不会假装成功，会明确告诉你缺什么。

**怎么退出**：右键托盘图标 → 退出。直接关主界面只是收起，进程还在，这是故意的——桌宠要在你干活时一直在。想让它开机自己出现，设置页把「开机自启」打开；不想了就在同一个地方关掉。

## 数据放在哪

| 存什么 | 在哪 |
| --- | --- |
| 项目、步骤、事项、计时流水、随手记、想法、对话、日总结 | `文档目录\app.db`（SQLite） |
| API key | `%APPDATA%\com.aipet\ai_pet_assistant\api_key.bin`，Windows DPAPI 加密 |

key 不进数据库、不进日志、界面上也不回显。这个加密文件只有当前用户在这台机器上解得开，拷走也没用。

**什么会发出去**：只有你主动点 AI 时的那一段文字、事项标题，以及你手动选中的附件内容。剪贴板、屏幕内容、整个数据库都不会被读取或上传。断网或额度用尽时，四处 AI 入口退回本地行为（想法留未分类、小结退回随手记整合），不报假成功。

**想清干净**：退出程序 → 删 `文档目录\app.db` → 删 `%APPDATA%\com.aipet\ai_pet_assistant\api_key.bin`。

## 已知边界

- **只有 Windows x64**。macOS 与 Linux 的 key 安全存储没有实现，那上面写 key 会明确失败，不做"悄悄存明文"这种降级。
- **单机**。没有账号、没有云同步；换机器要重新填 key，数据库得自己拷。
- 全屏应用（放视频、答辩演示）时桌宠仍会浮在上面，v1 没做全屏检测。
- 一个项目里的待办做完就自动换下一步，没有"明天再说"的静音开关。

## 开发

```powershell
cd app
flutter pub get
flutter run -d windows                              # 开发时跑
flutter test                                        # 647 条
dart analyze lib test                               # 必须 No issues found!
powershell -ExecutionPolicy Bypass -File tool\package_windows.ps1   # 出 dist 里的 zip
```

环境：Flutter 3.47.7 stable、Dart 3.11、Windows 10/11 x64。改了数据库表之后跑一次 `dart run build_runner build --delete-conflicting-outputs` 重新生成 `app_db.g.dart`（已入库，一般不用管）。

```
app/lib/
├── app/         壳、路由、主题、provider 装配
├── features/    按页切：pet panel tasks projects records ideas settings
├── domain/      实体、用例、端口（纯 Dart，不 import Flutter）
├── data/        drift 数据库、DAO、Repository、迁移
├── platform/    窗口、托盘、自启、安全存储、计时
└── ai/          客户端、提示词、结构化解析、降级
```

第一次 `flutter test` 需要能访问 GitHub：`sqlite3` 的构建钩子会去取一份预编译库（产物在 `.dart_tool/`，不入库）。网络不通会报 `Building native assets failed`；`flutter pub get` 与 `dart analyze` 不受影响。
